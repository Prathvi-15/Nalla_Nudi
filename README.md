# Nalla-Nudi – Bridge Dictionary App

## Project Description
Nalla-Nudi is an educational Android application developed for Kannada-medium students to help them understand English technical vocabulary easily. The application provides bilingual learning support with Kannada explanations, pronunciation support, quizzes, flashcards, spelling activities, and progress tracking.

The project aims to reduce the language barrier faced by students while learning technical subjects such as Science, Mathematics, and Commerce.

---

# Problem Statement
Students from Kannada-medium schools often face difficulties understanding English technical terms used in higher education. Traditional dictionaries do not provide simple educational explanations suitable for students.

Nalla-Nudi solves this problem by providing an interactive bilingual learning platform that improves vocabulary, pronunciation, and subject understanding.

# Installation Steps

## Clone Repository
```bash
git clone https://github.com/your-username/Nalla_Nudi.git
```

## Open Project
1. Open Android Studio
2. Click on Open Existing Project
3. Select the project folder

## Install Dependencies
Gradle dependencies will install automatically.

## Run Application
1. Connect Android device or start Android Emulator
2. Click Run ▶ button in Android Studio

---

